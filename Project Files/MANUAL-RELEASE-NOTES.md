Mochi Desktop 1.2.15 brings Ocean Cleanup and update notifications to the unsigned manual-download edition.

- Mochi checks for newer public releases at startup and through **Check for updates**. A new-version notification offers its official GitHub release page. Drafts and previews are excluded.
- Ocean Cleanup includes twelve litter designs, six Ocean Bins, randomized mouth or flipper pickups, a gentle chomp, and smooth acceleration and deceleration. Mochi and the cleanup artwork stay visible through overlaps.
- Downloads and installation remain manual. No account, API key or paid certificate is needed to use Mochi.

Download **Mochi-Desktop-1.2.15.zip** for an enclosing folder with the executable, instructions and test results, or download **Mochi.exe** on its own. Quit Mochi before replacing the executable in your existing folder. Keep your settings and `Project Files` folder.

This release is **unsigned**. Windows may show an unknown-publisher or SmartScreen warning. SHA-256 checksums identify the released files; they are not a Windows publisher signature.

Built against .NET Framework 4.8 and tested under Wine/Xvfb. See the included test report for the exact validation and executable hash; this is not a native Windows 11 test run.
