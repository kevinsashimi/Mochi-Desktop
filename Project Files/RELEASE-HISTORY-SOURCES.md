# Sources for Mochi's early release history

The entries before 1.1.4 in `CHANGELOG.md` were reconstructed on 6 October 2026
from the project's Git history and the development conversations requested by
the repository owner. Dates in the early timeline use Singapore time.

| Source | What it establishes |
| --- | --- |
| “Create cute whaleshark pet” | First pet art and directional poses on 11–12 September; Windows desktop companion and expanded reactions on 26 September; smoother motion, directional animation variants, interactions, and Come here on 30 September–1 October. |
| “Verify Mochi Desktop files” | Project file organisation, built-in updater, and publication of version 1.0.0 on 1 October. |
| “Mochi Desktop - Main” | Playful Mode preview 1.1.0, Energetic rename in 1.1.1, scheduling and status diagnostics in 1.1.2, and the desktop COM connection fix in 1.1.3. The user confirmed the feature worked after that fix. |
| Initial commit `2bede3d` | Source, artwork, README, and QA reports corroborate the unversioned desktop features; no assembly version was assigned there. |
| Commit `250d698` | The first explicit assembly version is 1.0.0.0, with updater and organised project files. |
| Commit `455eb51` | Published 1.1.4 combines the Playful Mode preview work and the independent activity scheduling fixes. |

Versions 1.1.0–1.1.3 were shared as test previews, not separate published GitHub
releases. Earlier development is grouped under **Early days**, without assigning
invented version numbers. Historical activity intervals are identified as such;
the current 1–3 minute interval is documented under 1.1.5.

The notes summarise user-visible outcomes. They do not reproduce private
transcripts, machine paths, or abandoned experiments.
